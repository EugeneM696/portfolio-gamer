## Лабораторна робота №6
- Величина: Обсяг даних
- 5 тестів parseValue:
1. 3 Б = 0,0029 КБ
2. 5 МБ = 5 242 880 Б
3. 6 ТБ = 6 144 ГБ
4. 12 ГБ = 0,0117 ТБ
5. 1 КБ = 0 ГБ
- Роль .slice() перед .sort(): оскільки метод .sort() змінює сам вихідний масив, перед сортуванням завжди створюйте його поверхневу копію за допомогою .slice(). Інакше після натискання кнопки «Ціна ↓» початковий порядок елементів у catalog назавжди загубиться, і кнопка «Усі» показуватиме вже пересортований список.
